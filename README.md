# joker-orbital-constraints
Using The Joker MCMC Sampling to provide orbital parameters of binary systems. Constrains the mass of the secondary object to a range using the primary objects known mass. Useful for variable RV's that suggest a hidden companion.
I highly suggest creating a separate environment through an environment manager such as Anaconda to host The Joker package coding on!
Need radial velocity measurements, the more measurements more efficient the MCMC draws will run.
