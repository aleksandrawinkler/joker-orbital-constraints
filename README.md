# joker-orbital-constraints
Using The Joker MCMC Sampling to provide orbital parameters of a binary system. Constrains the mass of the secondary object to a range using the primary objects known mass. Useful for variable RV's that suggest a hidden companion.
Highly suggest creating a separate environment through an environment manager such as Anaconda to host The Joker package coding on.
Need radial velocity measurements, the more measurements the shorter the time it will take for the MCMC draws to run.
